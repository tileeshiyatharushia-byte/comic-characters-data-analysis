# Comic Characters Data Analysis & Visualization

## Project Overview

This project analyzes and visualizes data about comic book characters from Marvel and DC using Python.

The main goal of this project is to explore the dataset, identify useful patterns, and present the findings using different data visualization techniques.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Kaggle Notebook
* GitHub

## Dataset

The dataset contains information about comic book characters from:

* Marvel
* DC

The dataset is based on the FiveThirtyEight Comic Characters Dataset.

## Project Steps

1. Import required Python libraries
2. Load Marvel and DC datasets
3. Explore the datasets
4. Combine the Marvel and DC datasets
5. Handle missing values
6. Check duplicate values
7. Clean the data
8. Perform data analysis
9. Create data visualizations
10. Identify important findings
11. Summarize the results

## Visualizations

The project uses different visualization techniques, including:

* Bar charts
* Count plots
* Line charts
* Scatter plots
* Histograms
* Heatmaps
